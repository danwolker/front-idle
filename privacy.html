Política de Privacidade

Última atualização: 25 de Julho de 2026

Esta Política de Privacidade descreve como o Idle Extension lida com as informações e dados dos usuários ao utilizar nossa extensão para navegador Google Chrome.

1. Coleta de Dados

O Idle Extension não coleta, armazena, transmite ou compartilha nenhum dado pessoal dos seus usuários. Não solicitamos cadastro, e-mail, nome, localização ou dados de pagamento dentro da extensão.

2. Uso de Armazenamento Local (Local Storage)

A extensão utiliza exclusivamente o armazenamento interno do próprio navegador (via APIs chrome.storage.local e chrome.storage.session) para guardar:

  • Preferências de interface do usuário (ex: atalhos, exibição de cards de bosses);
  • Métricas locais de caça (XP/h, loot acumulado) para exibição nos painéis;
  • Estado temporário da aba do jogo.

Todos esses dados permanecem 100% salvos no seu próprio dispositivo e nunca são enviados para servidores externos.

3. Permissões Solicitadas no Navegador

Solicitamos apenas as permissões estritamente necessárias para o funcionamento do recurso:

  • Host Permissions (baiakidle.com): Para permitir que a extensão exiba a interface HUD e leia estatísticas do jogo durante a partida.
  • Storage: Para salvar suas configurações de preferências localmente.
  • Alarms: Para manter o acompanhamento contínuo da sessão do jogo em segundo plano.
  • Host Permissions (tibiadata.com / tibiawiki.com.br): Para consultar informações públicas de loot e criaturas para exibição no hover.

4. Compartilhamento e Venda de Dados

Declaramos formalmente que:

  • Não vendemos nem transferimos dados de usuários a terceiros.
  • Não utilizamos dados para finalidades de rastreamento publicitário ou análise de crédito.
  • Não utilizamos código remoto executável. Todo o código é empacotado e auditado localmente.

5. Contato

Se você tiver qualquer dúvida sobre esta Política de Privacidade ou sobre o funcionamento do Idle Extension, entre em contato conosco através do nosso canal oficial de suporte.
